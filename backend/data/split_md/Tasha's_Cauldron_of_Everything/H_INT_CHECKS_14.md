# H Int Checks

Any character has the option of making these ability 
checks to receive a hint: 
Intelligence (Investigation) DC 15. The character 
notes the words "even" and "odd" in the verse on 
the room's floor and believes they have some sig­
nificance to the missing tiles. 
Wisdom (Perception) DC 10. The character 
can deduce which tiles correspond to which 
elementals.
