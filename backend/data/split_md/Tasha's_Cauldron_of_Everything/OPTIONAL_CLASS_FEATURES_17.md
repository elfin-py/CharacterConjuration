# Optional Class Features

You gain class features in the Player's Handbook 
when you reach certain levels in your class. This 
section offers additional features that you can gain 
as a paladin. Unlike the features in the Player's 
Handbook, you don't gain the features here automat­
ically. Consulting with your DM, you decide whether 
to gain a feature in this section if you meet the level 
requirement noted in the feature's description. 
These features can be selected separately from one 
another; you can use some, all, or none of them.
