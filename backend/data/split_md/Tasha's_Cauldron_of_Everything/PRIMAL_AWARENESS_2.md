# Primal Awareness

3rd-level ranger feature, which replaces the Prime­
val Awareness feature 
You can focus your awareness through the intercon­
nections of nature: you learn additional spells when 
you reach certain levels in this class if you don't 
already know them, as shown in the Primal Aware­
ness Spells table. These spells don't count against 
the number of ranger spells you know.
