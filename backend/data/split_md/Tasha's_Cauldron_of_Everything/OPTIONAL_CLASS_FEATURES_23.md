# Optional Class Features

You gain class features in the Player's Handbook 
when you reach certain levels in your class. This 
section offers additional features that you can gain 
as a cleric. Unlike the features in the Player's Hand­
book, you don't gain the features here automatically. 
Consulting with your DM, you decide whether to 
gain a feature in this section if you meet the level re­
quirement noted in the feature's description. These 
features can be selected separately from one an­
other; you can use some, all, or none of them. 
If you take a feature that replaces another feature, 
you gain no benefit from the replaced one and don't 
qualify for anything in the game that requires it.
