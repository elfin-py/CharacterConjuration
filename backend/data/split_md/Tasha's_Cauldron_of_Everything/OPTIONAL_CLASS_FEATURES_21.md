# Optional Class Features

You gain class features in the Player's Handbook 
when you reach certain levels in your class. This 
section offers additional features that you can gain 
as a barbarian. 
Unlike the features in the Player's Handbook, you 
don't gain the features here automatically. Consult­
ing with your DM, you decide whether to gain a fea­
ture in this section if you meet the level requirement 
noted in the feature's description. These features 
can be selected separately from one another; you 
can use one, both, or none of them.
