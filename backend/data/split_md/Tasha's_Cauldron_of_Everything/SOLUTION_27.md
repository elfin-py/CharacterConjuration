# Solution

Each painting features a number of creatures of 
a particular kind, as summarized in the Creature 
Paintings table. Counting into each creature's name 
by the number of creatures in the painting reveals a 
letter. When unscrambled, the letters spell out "owl­
bear." Characters are likely to reveal these letters in 
random order. Arranging them in the correct order 
is part of the puzzle.
