# Solution

An inventory of the room reveals gemstones in 
the amounts shown in the Gem Inventory table. 
The table lists the gems in alphabetical order, but 
you should list them in any other order when de­
scribing them to players so not to accidentally give 
away a hint. 


Each type of gem is associated with a letter of the 
alphabet, and each gem's letter is revealed by count­
ing into the alphabet by a number of letters equal to 
the number of gems of its type. For example, there 
is one piece of quartz, so "quartz" corresponds to 
the first letter of the alphabet (A), while there are 
fourteen amethysts, so "amethyst" corresponds to 
the fourteenth letter of the alphabet (N).
