# Skeleton Keys

Difficulty: Easy 
This puzzle presents a quick encounter useful for 
providing treasure or information. It features a box 
with four locks. · 
You come upon a sinister metal box with an iron lock 
built into each of its four sides. Each lock sports a 
keyhole with a sculpted image above it. Four iron keys 
hang from hooks on a nearby wall, and each key has a 
different number of teeth. Above the keys, the follow­
ing verse has been etched into the wall: 
The spells on these locks are all the same. 
Though each possesses a unique name. 
Count on your answer to unlock the way, 
But use the wrong key to your dismay. 
All four locks must be opened before the box's con­
tents (whatever they might be) can be accessed.
